# Regole per gli agenti (Codex, Claude)
1. Analizza il repository prima di modificare file.
2. Piccoli incrementi: un sistema alla volta.
3. Client, server e backend separati. Il client non decide mai denaro, oggetti o proprietà.
4. Esegui build e test dopo ogni modifica. Non dichiarare funzionante ciò che non hai provato.
5. Niente dipendenze inutili. Ogni decisione architetturale va in `Docs/DECISIONS.md`.
6. Gioco originale: niente nomi, mappe o grafica copiati da altri giochi.
