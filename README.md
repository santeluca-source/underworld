# UNDERWORLD
Gioco multiplayer open-world 3D per Windows (8–16 giocatori), stile Modern Low Poly.
Stato: pre-produzione. Brief: `Docs/BRIEF.md`. Architettura: `Docs/ARCHITECTURE.md`. Fasi: `Docs/ROADMAP.md`.

## Cartelle
- `UnityProject/` client Unity 6 LTS (URP) — progetto non ancora creato
- `GameServer/` server autoritativo
- `Backend/` ASP.NET Core (account, salvataggi, economia)
- `Database/` schema e migrazioni PostgreSQL
- `Infrastructure/`, `Tools/`, `Docs/`
